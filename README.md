# 주차장 찾기 · 주차요금 계산

목적지 주변 공영·민영 주차장 정보를 검색하고, 등록된 기본·추가 요금으로 예상 주차비를 비교하는 정적 웹 도구입니다.

## 기능

- 지역명·주소·주차장 이름 검색
- 브라우저 위치 권한을 허용하면 현재 위치에서 가까운 주차장 정렬
- 현재 위치 기준 1·3·5·10km 범위 검색과 지도상 내 위치 표시
- 지도에서 주차장 핀을 누르면 상세 요금과 주소 확인
- 무료 주차장 필터와 거리·예상 요금·주차 구획 수 정렬
- 30분부터 12시간까지 예상 요금 계산
- 주차장별 운영시간, 데이터 기준일, 지도 검색 링크 표시

## 데이터와 한계

- 공공데이터포털 [전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)를 사용합니다.
- 자료는 지방자치단체 등록 정보를 취합한 것으로 실시간 잔여 주차면을 제공하지 않습니다.
- 전국 단위 병합 자료는 월별로 갱신되며, 지역별 기준일이 다를 수 있습니다.
- 기본/추가 요금 데이터가 불완전한 주차장은 임의 계산하지 않고 “요금 확인 필요”로 표시합니다.
- 1일권, 할인, 무료 적용, 운영시간 경계 등 현장 규칙을 모두 반영하지 않은 예상치입니다. 이용 전 관리기관에 확인해 주세요.
- 지도는 Leaflet과 OpenStreetMap 타일을 사용합니다. 타일을 보려면 인터넷 연결이 필요하며, 지도가 요청하는 타일 범위로 대략적인 표시 지역이 타일 제공자에게 전달될 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 별도 공개 저장소의 최상위에 올립니다.
2. 공공데이터포털에서 전국주차장정보표준데이터 API 활용을 신청해 인증키를 발급받습니다.
3. 저장소의 **Settings → Secrets and variables → Actions**에 `DATA_GO_KR_API_KEY` 시크릿을 추가합니다. 서비스키는 HTML이나 공개 JSON에 넣지 마세요.
4. **Actions → Sync nationwide parking data → Run workflow**를 실행해 첫 데이터 스냅샷을 생성합니다. 월별 자동 갱신도 설정되어 있습니다.
5. **Settings → Pages**에서 `Deploy from a branch`, 기본 브랜치, `/(root)`를 선택합니다.

## 로컬 미리보기

Windows에서는 `start-local.bat`을 실행하거나 터미널에서 `node serve-local.mjs`를 실행한 뒤, 콘솔에 표시된 `http://127.0.0.1:8000/?demo=1` 주소를 여세요. `?demo=1`은 지도의 위치와 화면을 확인하기 위한 가상 예시 데이터를 사용하며, 실제 데이터가 아닙니다. 인증키 없이 검색·요금 계산·지도 화면을 확인할 수 있습니다. `file://`로 직접 열면 브라우저가 JSON 데이터 요청을 차단할 수 있습니다. 데이터 동기화 스크립트는 Python 표준 라이브러리만 사용합니다.

데모가 아닌 실제 배포 화면은 `http://127.0.0.1:8000/`로 엽니다. API 키를 등록하고 GitHub Actions를 실행하기 전에는 실제 주차장 데이터가 비어 있을 수 있습니다.
